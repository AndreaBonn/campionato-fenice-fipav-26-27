Come leggere la classifica
Pt
punti: 3 per una vittoria 3-0 o 3-1, 2 per un 3-2, 1 per una sconfitta 2-3
G, V, P
partite giocate, vinte, perse
Set
set vinti e persi
Q. set
quoziente set: set vinti diviso set persi
Q. punti
quoziente punti: punti fatti diviso punti subiti

A parità di punti conta il numero di vittorie, poi il quoziente set, poi il quoziente punti. Criterio provvisorio finché il Comitato non pubblica l'indizione.
